Matlab and Sage Code for Visualizing Discriminant Amoebae for Near-Circuits

This is a preliminary release of some of my Matlab code for visualizing the complex amoebae of A-discriminants, in the special case where A is a near-circuit. My code also allows you to view the image of the real zero set (unfolded across different quadrants if desired) under the log absolute-value map. More documentation will appear soon but in the mean time please feel free to pester me.

The following code was written by Jeff Sommars, as part of a final project for my 2011 REU class. (Postdoc Mounir Nisse, my Ph.D. student Korben Rusek, and I co-advised Jeff that summer.) It enables visualization of the coamoebae of A-discriminants, in the special case where A is a near-circuit. More documentation will appear soon but in the mean time please feel free to pester me.
