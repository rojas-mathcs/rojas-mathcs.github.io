HKPLOT: Matlab Code for Visualizing Archimedean Amoebae (and their Real Parts) in Dimension 2

This is a preliminary release of some code for visualizing the complex amoeba of a bivariate polynomial, along with the subset consisting of the image of the positive or real roots. More documentation will appear soon but in the mean time please feel free to pester me.

  • hkplot.m: usage: hkplot(a,cell,flip,piclim,res,cxres,fig,fold,cx,phasecolor);

    where...

    a = n x m support matrix

    cell = n-subset of [1,...,m] with det(a(:,cell)) odd...

    flip = possible flip of signs, for simplification/visualization purposes...

    piclim = [minx,maxx,miny,maxy], for picture

    res = density of points on parameter line

    fig = which figure for the picture

    fold = plot pos part, unfolded real part, or folded real part,

    according as fold=0,1,2

    cx = plot the traditional complex amoeba too!

    phasecolor = vary (or not) the interior color according to the phase

    of the pre-image under the Horn-Kapranov uniformization,

    according as 1 or 0
